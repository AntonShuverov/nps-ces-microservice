# Микросервис NPS CES

Сервис опросов клиентов на сайте: поп-ап с вопросами CES и NPS на шагах флоу (например, «займ выдан»), сбор оценок в собственную БД и загрузка в DWH.

Сервис только собирает оценки. NPS, CES и остальные метрики считаются в BI.

## Ключевые решения

- Опрос показывается при каждом новом наступлении события, но не чаще 1 раза в день на опрос.
- Лимиты показов и паузы после закрытия не используются.
- Условия показа гибкие: тип клиента, продукт, канал, номер займа, доля показа.
- Результат считается по каждому вопросу: если клиент ответил на CES и закрыл опрос на NPS, CES — «ответил», NPS — «закрыл».
- Шкалы: NPS 0–10, CES 1–7 (утвердить).
- Только сайт, только авторизованные клиенты.
