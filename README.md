# Розничные расходы в Европе — Анализ в Excel

## Задача

> В какой стране самое высокое соотношение затрат на питание к затратам на одежду?

## Данные

| Страна | Население (тыс.) | ВВП (млн) | Продукты питания (млн) | Одежда (млн) |
|---|---|---|---|---|
| Англия | 56 753 | 737 886 | 65 506 | 28 262 |
| Дания | 5 134 | 117 238 | 10 582 | 3 246 |
| Франция | 55 385 | 935 579 | 105 354 | 41 515 |
| **Италия** | **57 221** | **757 177** | **128 082** | **29 050** |
| Нидерланды | 14 704 | 253 206 | 21 773 | 7 937 |

## Решение

Формула соотношения для каждой страны:

```
Соотношение = Продукты питания / Одежда
```

| Страна | Расчёт | Результат |
|---|---|---|
| Англия | 65 506 / 28 262 | 2.318 |
| Дания | 10 582 / 3 246 | 3.260 |
| Франция | 105 354 / 41 515 | 2.538 |
| **Италия** | **128 082 / 29 050** | **4.409** ✅ |
| Нидерланды | 21 773 / 7 937 | 2.744 |

## Формулы Excel

| Ячейка | Формула | Описание |
|---|---|---|
| `F4` | `=D4/E4` | Соотношение для каждой страны (протянуть до F8) |
| `B11` | `=MAX(F4:F8)` | Максимальное соотношение |
| `B12` | `=INDEX(A4:A8,MATCH(MAX(F4:F8),F4:F8,0))` | Страна с максимальным соотношением |

## Ответ

**C. Италия** — соотношение **4.409** (наибольшее среди всех стран)
